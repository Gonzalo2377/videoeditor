# Editor de vídeos de scouting

Montador de clips: cargar clips (carpeta o zip), organizarlos, editar cada clip (pausas, seguir jugador,
zoom, cámara lenta, texto) y generar el vídeo. Todo funciona en el navegador: los clips no se suben a ningún sitio.
